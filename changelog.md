# Changelog

## 2.1.0

- Added config toggle `LootChests.useVanillaEnchantedBookRolls` (default true) so the Hammer book now uses vanilla enchanted_book rolls instead of a custom guaranteed pool; set to false to keep the old custom drop chance behavior.
- Lowered default Hammer chest book drop chance to 5% and clamp the value to 0–1 when using the custom pool.
